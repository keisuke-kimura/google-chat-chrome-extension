Chat Booster の設定

Google Chat API 経由で参加している全スペースを監視し、 自分宛のメンションを検知して通知します。まず下の「Google アカウントに接続」から。

承認済みのリダイレクト URI
—
この値を Cloud Console の OAuth クライアント（種類: ウェブ アプリケーション）の「承認済みのリダイレクト URI」に 末尾の / まで含めてそのまま登録してください。 1文字でも違うと redirect_uri_mismatch になります。
Google Cloud 側のセットアップ手順（初回のみ）
  1. Google Cloud Console でプロジェクトを作成
  2. Google Chat API を有効化 （API ライブラリ）
  3. Chat API の「設定」タブでアプリ名・アバターURL・説明を入力して保存。 読み取り専用の用途でも、ここが空だと 403 になります。
  4. OAuth 同意画面を作成。社内 Workspace なら「内部」を選ぶと Google の審査が不要です。
  5. 認証情報 → OAuth クライアント ID → 種類 「ウェブ アプリケーション」を選択し、 「承認済みのリダイレクト URI」に上の URI を登録
  6. 発行されたクライアント ID（必要ならシークレットも）を上の欄に貼り付け
  7. 「Google アカウントに接続」を押す

何を通知するか

自分宛の @メンション は API のアノテーションで判定するので、 設定なしで正確に拾えます。以下は追加で拾いたいものです。

通知

取得

Chat API には拡張機能へ通知を push する仕組みが無いので定期取得します。 Chrome の制約で実効の下限は 30 秒です。短くするほど API 使用量が増えます。

サイドパネルの「未読」タブ用。1スペースあたり2リクエスト使うため、 メンション検知より長めにしています。

操作

  • Alt + S … カーソル上／選択中のメッセージを保存
  • Alt + Shift + S … サイドパネルを開く

ショートカットは chrome://extensions/shortcuts で変更できます。

変更は自動保存されます
