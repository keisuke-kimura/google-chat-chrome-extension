Chat Booster の設定

Google Chat API 経由で参加している全スペースを監視し、 自分宛のメンションを検知して通知します。まず下の「Google アカウントに接続」から。

接続できないときは（Cloud 側のセットアップ手順）
  1. Google Cloud Console でプロジェクトを作成
  2. Google Chat API を有効化し、「設定」でアプリ名・アバターURL・説明を入力して保存（ユーザー認証だけでもこの設定が必須）
  3. OAuth 同意画面を 内部 (Internal) で作成（社内 Workspace なら Google の審査は不要）
  4. 認証情報 → OAuth クライアント ID → 種類「Chrome 拡張機能」→ アイテム ID にこの拡張の ID を入力
  5. 発行されたクライアント ID を manifest.json の oauth2.client_id に貼り付けて、拡張をリロード

詳細は同梱の README.md に。Chrome 本体に対象の Google アカウントで ログインしている必要があります。

何を通知するか

自分宛の @メンション は API のアノテーションで判定するので、 設定なしで正確に拾えます。以下は追加で拾いたいものです。

通知

取得

Chat API には拡張機能へ通知を push する仕組みが無いので定期取得します。 Chrome の制約で実効の下限は 30 秒です。短くするほど API 使用量が増えます。

操作

  • Alt + S … カーソル上／選択中のメッセージを保存
  • Alt + Shift + S … サイドパネルを開く

ショートカットは chrome://extensions/shortcuts で変更できます。

変更は自動保存されます
